# Codex Milestone Logs

Codex must create one chronological log per H!veAI milestone in this directory.

Filename pattern:

`MXX_<SHORT_NAME>_CODEX_LOG.md`

Example:

`M02_UI_SHELL_CODEX_LOG.md`

Each log must start before code changes and contain:

- phase name
- phase status
- repository
- branch
- starting HEAD
- current HEAD
- start timestamp
- chronological checkpoints
- commands and exit results
- files inspected/changed
- architecture decisions and reasons
- failures and subsequent fixes
- tests and results
- git status checkpoints
- commits
- push status
- unresolved blockers

At completion add a final summary and mark `PHASE STATUS: COMPLETE` only when the milestone acceptance criteria have been verified.

Do not delete old failures from the chronology after they are fixed.
Do not store secrets or credentials in logs.
